# ImageChannelsViewer

## Description
ImageChannelsViewer is a Python learning project for loading an image and displaying each color channel (R, G, B, and alpha channel if present) separately. This is useful for learning about image structure and color basics.

## Libraries used
- numpy - for working with arrays
- imageio - for reading images
- matplotlib - for displaying images

## How to use
1. Install the required libraries:
 pip install numpy imageio matplotlib

2. Replace the path to the image with your file in the script.

3. Run the script:
 python your_script.py

4. In the window that appears, you will see the original image and the Red, Green, Blue, and (if available) Alpha channels separately.

## Features
- Fast loading and output of image channels.
- Visualization of channels with different color palettes.
- Easily extensible for additional processing.
